# Prioritized next steps

## 1. Improve scientific traceability

Add per-parameter reference links and uncertainty/limit fields through a second bounded TAP request or a normalized companion snapshot. Let a user move from a displayed value to the exact underlying publication and understand composite-row inconsistencies in more detail.

## 2. Strengthen the atlas model

Offer observed-sky and galactic-coordinate projections, a clear distance-scale legend, and accessible system labels without making missing distances look measured. Add a proper keyboard-navigable spatial index for atlas points beyond search and sibling alternatives.

## 3. Split and tune rendering

Lazy-load Three.js, isolate the renderer chunk, and profile on physical integrated-GPU phones. Introduce an adaptive quality controller based on measured frame time, while retaining the static fallback. The existing software-Chromium FPS numbers are diagnostics, not hardware benchmarks.

## 4. Deepen world reconstruction responsibly

Add physically clearer atmosphere/haze models and more distinct rocky/cloud treatments, still seeded and labeled. Use actual atmospheric spectroscopy only when a separate source supports it; never infer composition from color or class.

## 5. Add a postcard view

Only after the core remains polished: render a shareable static postcard from the same recipe, camera, evidence labels, and attribution. Include reduced-motion and no-WebGL export paths.

## 6. Expand validation

Add automated visual-diff tolerances, keyboard-focus trapping checks for the evidence dialog, physical-device touch testing, offline cold-start checks, and periodic snapshot-schema drift checks.
